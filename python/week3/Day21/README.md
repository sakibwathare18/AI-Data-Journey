# Student Data Processing Pipeline

## Description

A Python-based data processing pipeline that
cleans, validates, transforms and analyzes
student records.

## Concepts Used

- Functions
- *args
- **kwargs
- Decorators
- Regular Expressions
- Generators
- List Comprehensions
- Lambda
- filter()
- Dictionaries
- Exception Handling

## Pipeline

Raw Data
→ Parse
→ Validate
→ Clean
→ Transform
→ Filter
→ Statistics

## Purpose

This project was created as part of my Python
learning journey toward Data Science and
Data Engineering.
