# Day 28 — NumPy Student Performance Analyzer

## Objective

Build a practical student performance analysis system using NumPy.

## Dataset

- 20 students
- 5 subjects
- 100 marks

## Subjects

- Python
- SQL
- Java
- Statistics
- Machine Learning

## NumPy Concepts Used

- NumPy arrays
- Array shape
- Axis operations
- Mean
- Median
- Minimum and maximum
- Standard deviation
- Boolean filtering
- argmax()
- argmin()
- argsort()
- Random data generation
- 2D array analysis

## Analysis Performed

- Student averages
- Subject averages
- Best and weakest subject
- Best and weakest student
- Pass/fail analysis
- Performance categories
- Student ranking
- Highest mark detection
- Standard deviation analysis

## Learning Outcome

This project demonstrates how NumPy can be used for practical numerical data analysis.
